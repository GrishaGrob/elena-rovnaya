# Website architecture v9

1. Header: name, sections, CTA.
2. Hero: life situation first, descriptor `Психолог · гештальт-подход`.
3. Recognition cards: money, self-worth, relationships, inner support, motherhood.
4. Gestalt approach: explain through experience, not theory.
5. About Elena: education, life experience, boundaries.
6. How consultation works: introduction → exploration → work with request → observations → next step.
7. Reviews/cases: only real, permission-based, no guaranteed outcome.
8. FAQ: method, online/offline, duration, confidentiality, how to know if psychologist fits.
9. Final CTA: write / book a consultation.

## Behaviour
- Mobile-first, wide spacing, editorial rhythm.
- Sticky CTA on mobile, discreet sticky header on desktop.
- Smooth anchor scrolling; restrained reveal animations.
- FAQ accordion; no autoplay video/audio.
- Forms: name + contact + preferred format only; no sensitive history in lead form.
- Accessibility: readable contrast, 16px+ body text, alt text, keyboard-visible focus.
