# Project instructions — Elena Rovanya website

## Source of truth
- Brand visuals: `brand/ELENA_ROVNAYA_Brand_Book_v11.pdf` and `brand/assets/`.
- Website strategy/content: `docs/WEBSITE_BRIEF.md` and `docs/COPY_AND_CONTENT.md`.
- Do not invent factual data that is not in these files.

## Product goal
Build a premium editorial personal-brand site for psychologist Elena Rovanya. The brand is warm and humane, but has strength, depth, financial-theme energy and movement. Public descriptor: `Психолог · гештальт-подход`.

## Code conventions
- TypeScript for new code.
- Keep site copy centralized in one content/config module.
- Use existing brand assets before adding generic icons/images.
- Do not hardcode arbitrary brand colours; define semantic CSS variables/tokens.
- Maintain accessible HTML and visible focus states.
- Every image must preserve aspect ratio and use intentional object-position.
- Respect reduced motion.

## Never invent
Price, phone, Telegram/VK, address, testimonials, credentials, client counts, guaranteed outcomes.
