# Elena site build

Use this skill when building or substantially redesigning the Elena Rovanya website.

1. Read the brand book and all `docs/` files.
2. Inventory brand assets and map each asset to planned sections.
3. Define semantic design tokens before building sections.
4. Build the page in content hierarchy order, not by copying a template.
5. Centralize copy/config and allow incomplete real-world data to hide gracefully.
6. Implement responsive compositions for desktop/tablet/mobile separately.
7. Run full visual QA and compare against brand mood before finishing.
8. Reject any component that feels generic even if technically polished.
