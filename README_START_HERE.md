# ELENA ROVNAYA — Cursor website handoff

Этот пакет предназначен для сборки сайта Елены Ровной в Cursor.

## Что сделать в Cursor
1. Создай/открой папку проекта сайта.
2. Распакуй содержимое этого архива в корень проекта.
3. Открой `MASTER_PROMPT_FOR_CURSOR.md` и вставь его первым сообщением в Cursor Agent.
4. Попроси Cursor сначала прочитать `AGENTS.md`, `brand/`, `docs/` и `.cursor/rules/`, а уже потом менять код.
5. Если проект новый — Cursor сам создаёт каркас по правилам из prompt. Если код уже существует — он сначала проводит аудит и сохраняет рабочую архитектуру.

## Источники истины
1. `docs/WEBSITE_BRIEF.md` — смысл и UX.
2. `brand/ELENA_ROVNAYA_Brand_Book_v11.pdf` — визуальная и брендовая рамка.
3. `brand/assets/` — реальные логотипы, иконки, маркеры и фото.
4. `docs/COPY_AND_CONTENT.md` — тексты и допустимая терминология.
5. `.cursor/rules/` — постоянные правила для агента.

## Важно
Не придумывать цены, адрес, телефон, мессенджеры и отзывы. Если данных нет — использовать централизованные TODO-плейсхолдеры в контент-конфиге и не выводить вымышленные данные пользователю.
